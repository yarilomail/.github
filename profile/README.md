# Yarilo Mail

Open-source email infrastructure written in Go.

## Mission

Email is too important to run on fragile infrastructure. Our mission is to make
self-hosted email boring: horizontally scalable, config-driven and Kubernetes-native,
so operators of any size can run their own mail platform without fear.

## Sponsorship
